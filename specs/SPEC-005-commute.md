## PR-1 · 버스 데이터

### T1 API 확인 (먼저, 막히면 멈추고 보고)
- 자료원: 국토교통부 **TAGO 버스노선정보**(`BusRouteInfoInqireService`: 노선번호목록, 노선정보항목(intervaltime 평일 배차 간격·첫차·막차), 노선별경유정류소목록)와 **TAGO 버스정류소정보**(`BusSttnInfoInqireService`: 정류소 좌표·이름·ID, 정류소별경유노선). 도시코드 목록 조회로 전주시 도시코드를 먼저 확인
- `.env`의 `DATA_GO_KR_SERVICE_KEY`로 실제 호출해 응답 항목을 `docs/bus/api_fields.md`에 갱신(전주시 GW 확인 결과는 그대로 남겨 두고 TAGO 절 추가)
- **원 응답은 바이트 그대로**(`response.content`) `data/raw/bus/tago/`에 저장하고, 문자 인코딩은 응답 헤더·XML 선언으로 판단해 한글 정류장 이름이 깨지지 않는지 먼저 확인(전주시 GW에서 이름이 손실된 원인도 같은 방식으로 한 줄 기록)
- 호출 수를 보고. 필요한 항목(정류장 좌표·이름, 노선별 정류장 순서와 방향, 평일 배차 간격)이 없으면 **멈추고 보고**

### T2 정류장 → 법정동
- 승강장 응답에 법정동 또는 지번 주소가 있으면 그것을 쓴다
- 없으면 공식 법정동 경계(국토교통부·국가공간정보포털·브이월드 등)를 찾아 출처를 기록. 로그인 다운로드가 필요하면 **멈추고 사람이 받을 파일명·경로를 보고**(받은 파일은 `data/raw/boundary/`, 커밋 제외)
- 결과: `outputs/bus/stops_by_dong.csv` (정류장 ID, 이름, 좌표, 법정동, 판정 방법)

### T3 캠퍼스 정류장 (D-044)
- `docs/bus/campus_stops.md`에 캠퍼스별 후보 정류장 표(ID, 이름, 기준 정류장과 거리)를 기록하고, 사람 확인 결과를 **확정/제외(사유)**로 표시. T4는 확정 ID만 사용

### T4 동 → 캠퍼스 직행 (D-045)
- 노선별 학교 방향 순서에서 동 안 정류장 다음에 캠퍼스 정류장이 나오는 경우만 직행으로 셈
- 동별·캠퍼스별: 직행 노선 수, 최소 정류장 수, 동 안 직행 탑승 정류소별 최솟값의 중앙값·탑승 정류소 수, 직행 노선 중 가장 짧은 평일 배차 간격(TAGO intervaltime, 분), 기준일. 통학권 판정은 최소 20정류소 이하 그대로
- 결과: `outputs/bus/commute_access.csv`, NUMBERS.md N-037 `미검증`

## PR-2 · 예산 추천·계약 판단에 통학권 추가 (PR-1 머지와 캠퍼스 정류장 확정 후)

### 엔진·API
- `budget_search`: 범위를 D-046대로 넓히고 조합에 통학 정보·캠퍼스 주변 대비 차이 추가, priority `commute` 추가. 대학가 동만 쓰는 기존 동작은 옵션(`scope="campus"`)으로 남겨 기존 결과와 N-036을 그대로 재현
- `judge`: 선택 인자 `dong`(통학권 동). 주면 그 법정동 거래만으로 비교(D-047). 없으면 기존과 동일
- `/api/budget`, `/api/judge`에 반영, `/api/meta`에 대학가별 통학권 동 목록과 통학 정보
- 기준 산출물: `outputs/compare/budget_commute_example.json`(효자동권·전북대권 각각 보증금 500, 월세 35, 최소 15㎡, 저렴함 순) → N-038 `미검증`

### 화면
- 예산 카드: 동 이름 옆 통학 배지("캠퍼스 주변" 또는 "버스 정류장 ○개"), 아래 한 줄 "직행 ○개 노선, 가장 자주 오는 버스 ○분마다"와 "캠퍼스 주변보다 월세 ○만 원 저렴해요/비싸요"
- 우선순위 세그먼트에 "통학 가깝게" 추가
- 카드 → 계약 판단으로 넘길 때 그 동을 선택한 상태로 이동
- 계약 판단 패널: 대학가 아래 "동네" 선택(기본 "캠퍼스 주변", 그다음 통학권 동 목록과 정류장 수)
- 대학가 비교 탭: 표 아래 "통학권 동네" 카드(동별 정류장 수·직행 노선 수·배차 간격·원룸·투룸·빌라 보통 조건)
