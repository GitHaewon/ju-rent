## API (`api/`)
| 항목 | 내용 |
|---|---|
| 실행 | `uvicorn api.main:app --reload --port 8000` |
| `GET /api/meta` | 대학가 목록, 집 종류(코드·한글 이름·설명), 환산율 설정(기본값·기준금리·기준일·최소·최대), 데이터 기준일 |
| `POST /api/judge` | 입력: campus, housing_type, area, deposit, monthly, construction_year(선택), rate_pct(선택) → `engine.judge()` 결과를 **그대로** 반환(필드 추가·변경 금지). 입력 오류는 422와 한국어 메시지 |
| `POST /api/explain` | 입력은 `/api/judge`와 같음. **서버에서 judge를 다시 계산**한 뒤 `ai_explanation()` 호출(화면이 보낸 결과 dict는 받지 않음). 반환: `{text, source: "ai"/"rule", reason}` |
| 보안 | `.env` 키는 서버에서만 읽음. 응답·로그에 키 금지 |

## 웹 (`web/`)
| 항목 | 내용 |
|---|---|
| 기술 | Vite + React + TypeScript, 애니메이션은 `motion`(Framer Motion). UI 컴포넌트 라이브러리 금지. 스타일은 시안의 CSS 변수(`:root`)를 그대로 옮긴 CSS |
| 글꼴 | `pretendard` npm 패키지로 직접 포함(CDN 금지) |
| 실행 | `npm install` → `npm run dev` (Vite proxy로 `/api` → `localhost:8000`). README에 API·웹 두 명령 실행법 |
| 데이터 흐름 | 입력 변경 후 250ms 디바운스 → `/api/judge`. 응답 오기 전에는 **이전 결과를 그대로 두고** 패널 위쪽에 작은 진행 표시만(깜빡임 금지). 오류는 해당 입력 아래에 이유와 고칠 방법 |

### 화면 구성 (시안 순서)
| 영역 | 내용 |
|---|---|
| 조건 패널 | 대학가 세그먼트(효자동권/전북대권), 집 종류 4개, 면적 슬라이더(㎡ + 평), 보증금·월세(정수, 만 원), 관리비(선택), 건축년도(선택 토글), 환산율 슬라이더(기본 D-026, 아래에 근거 문구) |
| 판단 카드 | 맥락 한 줄, 큰 판단 글자(판단 색), "비슷한 방 100곳 중 N곳이 이 방보다 쌌어요"(N = 백분위 반올림), 환산 월세, 매달 내는 돈 |
| 분포 카드 | API `histogram_10k_krw` 막대 + 분위수(p25·p75·p90)로 나눈 판단 색 띠 + "이 방" 핀. 부제는 실제 비교 조건 문장(적용 단계에 따라 "면적 ±10㎡로 넓혀"·"2021년부터로 넓혀" 반영) |
| 숫자 타일 3개 | 중간값(p50) / 비교한 거래(n, 기간) / 비싼 편이 되는 선(p75) |
| 건축연도 결과 | 건축년도 입력 시에만: 같은 경과연수구간 n·판단·백분위. 표본 부족이면 그렇게 표시 |
| 설명 카드 | "AI 설명 듣기" → `/api/explain`. `source=rule`이면 설명 아래 작게 "AI 설명을 쓰지 못해 기본 설명을 보여드려요(사유)" |
| 알아두세요 | API `warnings` 목록 + 자료 출처·기준일 |
| 모바일 | 900px 이하 한 열. 판단 카드가 화면 밖이면 위쪽에 작은 글래스 알약(판단 + 환산 월세 + "결과 보기") |
| 표본 부족 | 판단 글자 "판단 보류"(회색), "비슷한 거래가 N건뿐이라 판단하기 어려워요. 면적이나 집 종류를 바꿔 보세요." 분포·타일은 있는 정보만 |

### 판단 색 (시안과 동일)
저렴한 편 `#1F9D7A` / 보통 `#4568D6` / 비싼 편 `#E2862B` / 많이 비싼 편 `#D9465A` / 판단 보류 `rgba(30,34,69,.38)`

### 모션 규칙
1. 첫 진입 한 번만: 카드가 아래에서 살짝 올라오며 나타남(지연 합 0.24초 이내)
2. 결과가 바뀔 때: 숫자는 이전 값에서 새 값으로 0.45초 감속 전환, 핀은 스프링(stiffness 260, damping 26)으로 이동, 막대 높이·판단 색은 0.4~0.5초 전환
3. 세그먼트 선택 표시는 스프링으로 미끄러짐. 버튼은 누를 때만 살짝 작아짐(0.97)
4. 카드 hover 들어올림·반복 애니메이션 금지
5. `prefers-reduced-motion`이면 모든 전환 끔

### 문구 원칙
- 학생 눈높이의 존댓말, 개발 용어 금지("표본 확대 단계", "p25", "analytic" 등). 시안 문구를 기본으로
- 한국어 줄바꿈은 `word-break: keep-all`
