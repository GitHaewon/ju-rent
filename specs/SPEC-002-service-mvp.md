### T2 환산 월세 (D-026)
- `config/settings.toml`: `base_rate_pct = 3.00`, `base_rate_date = "2026-10-22"`, `legal_spread_pct = 2.0`, `legal_cap_pct = 10.0`, `user_min_pct = 2.0`, `user_max_pct = 10.0`
- 기본 r = min(legal_cap, base_rate + spread). 범위 밖 r 입력은 오류

### T3 유사 거래 선택 (D-027, D-028)
- 입력: 대학가, 주택유형, 면적, (선택) 건축년도
- 반환: 선택된 거래, 적용 단계(기본 / 면적 ±10㎡ / 기간 확대), 최종 n. 마지막 단계에서도 30건 미만이면 `표본 부족`

### T4 판단 (D-029)
- 백분위 = (입력보다 작은 거래 수 + 같은 거래 수 × 0.5) ÷ n × 100 (월세 30만 원처럼 같은 값이 많으므로 동점 절반 규칙 고정)
- 분위수(25·50·75·90)는 `numpy.percentile(method="linear")`
- 건축년도를 입력하면 같은 경과연수구간 안의 백분위도 따로 계산(30건 미만이면 `표본 부족`)

### T5 결과 JSON
`judge(...)`가 dict 반환: 입력값, 적용 r, 환산 월세, n, 적용 단계, 비교 기간, 분위수, 백분위, 라벨, 구간별 결과, 경고 목록, 데이터 기준일. 화면과 설명 문장은 이 dict만 사용
