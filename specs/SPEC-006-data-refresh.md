# SPEC-006 · 실거래 데이터 갱신 (국토부 API)

- 참조: D-003, D-013, D-024, D-027, D-028, N-020
- 목적: 지금 서비스 데이터는 사람이 내려받은 CSV(2021-01~2026-10, 2026-11-07 내려받음)에서 멈춰 있다. 이미 발급받은 국토부 전월세 실거래 API로 새 달을 받아 서비스를 최신으로 유지한다
- 규칙: AGENTS.md 그대로. **검증된 근거 수치(N-001~N-039)는 지금 스냅샷 기준으로 고정**하고, 서비스 화면만 최신 데이터를 쓴다

| PR | 브랜치 | 내용 | 고위험 |
|---|---|---|---|
| PR-1 | `feat/rtms-api` | API 수집기 + CSV와 같은 열로 변환 + 겹치는 기간 대조(통과해야 PR-2 진행) | **예** (유효 표본의 원천) |
| PR-2 | `feat/data-refresh` | 서비스 데이터에 갱신 적용, 기간 기준을 데이터 끝 달에 맞춰 자동 이동, 화면 기준일 표시 | **예** (비교 기간·판정 대상 변경) |

## 결정 (PR-1에서 D-049·D-050, PR-2에서 D-051·D-052를 DECISIONS.md 확정에 그대로 추가)
- `D-049 | 2026-11-15 | 갱신 자료원은 국토교통부 아파트·연립다세대·단독다가구·오피스텔 전월세 실거래 API(법정동 코드 52111·52113, D-024). 사람이 내려받은 CSV는 2021-01~2026-10 기준 원본으로 보존 | 공식 자료, 이미 활용신청·키 보유, CSV 수작업 반복 제거 | 확정`
- `D-050 | 2026-11-15 | API 자료는 CSV와 겹치는 완결된 달(2025-01~2026-08)에서 유형·구·월별 행 수와 핵심 필드(계약일·법정동·면적·보증금·월세·전월세구분·계약구분·건축년도) 다중집합이 일치해야 서비스에 쓴다. 불일치가 있으면 원인을 기록하고 사람이 결정 | 원천이 바뀌어도 유효 표본 정의(D-011)가 그대로 유지되는지 확인 | 확정`
- `D-051 | 2026-11-15 | 검증된 근거 수치(N-001~N-039)와 그 산출물은 2026-11-07 CSV 스냅샷 기준으로 고정한다. 서비스 화면(계약 판단·예산·대학가 비교)은 최신 갱신 데이터를 쓰고, 화면에 데이터 기준일(마지막 계약 달)과 갱신일을 표시한다 | 발표 근거는 재현 가능해야 하고, 서비스는 최신이어야 함 | 확정`
- `D-052 | 2026-11-15 | 기간 기준은 데이터 끝 달에 맞춰 자동 이동: 최근 24개월 = 끝 달 포함 24개월, 신고 미완성 표시 = 끝 달과 그 전 달(D-013), 부분 연도 = 끝 달이 12월이 아닌 해. 갱신 때마다 최근 3개월은 API로 다시 받아 통째로 교체(신고 지연·정정 반영) | 고정 날짜(2024-11~2026-10)는 시간이 지나면 틀려짐 | 확정`

## PR-1 · API 수집기 + 대조

| # | 작업 | 산출물 | 완료 기준 |
|---|---|---|---|
| T1 | API 응답 항목 확인 | `docs/rtms_api_fields.md` | 4개 유형 응답 필드와 CSV 열의 대응표(이름·단위·형식, 면적 기준 D-011 포함). 대응이 안 되는 CSV 열은 "API에 없음"으로 |
| T2 | 수집기 | `src/fetch_rtms.py` | 유형 × 구(52111·52113) × 계약월. 원 응답은 바이트 그대로 `data/raw/rtms_api/YYYYMM/`(커밋 제외), 페이지 끝까지, 호출 수·실패 기록. 재실행 시 저장본 재사용(`--refresh`로만 다시 받기). 키는 `.env`에서만, 출력·로그에 금지 |
| T3 | CSV 형식 변환 | `src/rtms_to_rows.py` | API 행을 기존 정제 단계가 받는 열·값 형식(만 원 단위, 계약년월·계약일, 계약구분 "-" 처리 등)으로 변환. 기존 `analyze_rentals`·`jurent.data` 필터를 그대로 통과 |
| T4 | 대조 (D-050) | `outputs/audit/rtms_api_vs_csv.json` | 2025-01~2026-08 유형·구·월별: CSV 행 수, API 행 수, 핵심 필드 다중집합 차이(건수와 예시 5행). 유효 표본(D-011) 기준 대학가·통학권 월별 건수 차이도. NUMBERS.md N-040 미검증 |

- 불일치가 있으면 **멈추고 보고**: 어떤 필드·어떤 달인지, 원인 추정(정정·해제·반올림 등)은 "추정"으로 표시
- 호출량: 4 × 2 × 20개월 = 160회 + 페이지. 하루 한도 안에서 나눠 받기 가능하게
