# 국토부 전월세 API와 보존 CSV 열 대응 (SPEC-006 T1)

공식 자료: [아파트](https://www.data.go.kr/data/15126474/openapi.do), [연립·다세대](https://www.data.go.kr/data/15126473/openapi.do), [단독·다가구](https://www.data.go.kr/data/15126472/openapi.do), [오피스텔](https://www.data.go.kr/data/15126475/openapi.do). 네 서비스는 `LAWD_CD`(52111·52113), `DEAL_YMD`(YYYYMM), `serviceKey`로 조회한다. 아래 응답 이름은 `data/raw/rtms_api/202501/`에 저장된 각 유형의 XML 원문에서 확인했다. 원문은 수신 바이트 그대로 저장하며 Git에 넣지 않는다.

|---|---|---|---|---|---|
| `NO` | API에 없음 | API에 없음 | API에 없음 | API에 없음 | 변환 순서의 1부터 시작하는 번호. 거래 식별자로 쓰지 않음 |

| `번지` | `jibun` | `jibun` | API에 없음 | `jibun` | 문자열. 단독·다가구 지번은 원문에서 제공되지 않음 |
| `본번`·`부번` | `jibun`에서 파생 | 동일 | API에 없음 | 동일 | 숫자 지번이면 4자리 0채움, 불가능하면 빈칸 |

| `계약년월`·`계약일` | `dealYear`, `dealMonth`, `dealDay` | 동일 | 동일 | 동일 | 계약월 YYYYMM, 일 1~31. 요청 월과 일치 검증 |
| `보증금(만원)`·`월세금(만원)` | `deposit`, `monthlyRent` | 동일 | 동일 | 동일 | 만 원, 쉼표 포함 가능. 단위 환산 없음 |

변환기는 `src/rtms_to_rows.py`다. 해당 유형의 2025년 보존 CSV 헤더와 같은 열 순서로 출력한다. `NO`와 API에 없는 보조 열은 D-050 핵심 필드 대조에 쓰지 않는다. 단독·다가구 지번과 일부 도로명 등 API에서 제공하지 않는 값은 추정하거나 다른 자료로 채우지 않는다.

대조에서는 아파트·연립다세대·오피스텔의 번지와 단지명(연립다세대는 건물명)을 거래 키에 포함한다. 이 유형들의 번지 문자열은 가공하지 않아 마스킹된 문자열도 그대로 비교한다. 단독·다가구 API 응답에는 번지가 아예 없어 보존 CSV의 마스킹 번지와 대조할 수 없다. 이 유형은 공통 거래 필드만 짝짓고 CSV의 마스킹 번지는 감사 결과에 원문대로 기록한다.
