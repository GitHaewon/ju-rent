# 건축물대장 API 조사 (SPEC-001 T5, Q-009)

조사일: 2026-11-07. API 호출이나 원자료 수집은 하지 않았다.

## 공식 출처와 확인된 범위

- [국토교통부 건축HUB 건축물대장정보 서비스 공식 명세](https://www.data.go.kr/data/15134735/openapi.do): 기본개요·총괄표제부·표제부 등의 속성정보를 제공하는 REST 서비스. 공식 [기계 판독 메타데이터](https://www.data.go.kr/catalog/15134735/openapi.json)에 기본 주소 `https://apis.data.go.kr/1613000/BldRgstHubService`, XML/JSON 형식, 월간 갱신, 무료 이용이 명시되어 있다.
- **확인된 요청 변수**: `_type=xml` 또는 `_type=json`(생략하면 XML). 시군구코드·법정동코드·지번·페이지·인증키의 **정확한 API 요청 변수명과 필수 여부는 확인 불가**. 공개 메타데이터에는 오퍼레이션별 요청 표가 없고, 이번 조사에서 포털의 상세 활용명세를 열지 못했다. 이를 추정해 호출 코드를 만들지 않는다.
- **사용승인일**: 동일 원천의 [국토교통부 건축물대장 표제부 파일 설명](https://www.data.go.kr/data/15044720/fileData.do)에 `사용승인일` 열이 명시되어 있다. 다만 위 API의 특정 오퍼레이션 응답에도 이 필드가 있는지는 **확인 불가**. API 응답 명세 또는 승인된 키로 실제 응답을 확인해야 한다.
- **무료 한도**: 무료 제공은 공식 메타데이터에서 확인. 개발·운영 계정의 일일 호출 한도는 **확인 불가**. 접근 가능한 메타데이터에 트래픽 숫자가 없으므로 활용신청 화면에서 확인해야 한다.

## 실거래 자료와의 연결 판단

표제부 파일 설명에는 시군구코드·법정동코드·번·지·관리건축물대장PK가 있다. 그러나 실거래 단독·다가구의 지번은 `data/audit/counts.json`의 N-008처럼 대부분 마스킹되어 있다. 따라서 **개별 단독·다가구 계약을 특정 표제부 건물에 일대일 연결할 수 있는지는 확인 불가**다. 마스킹된 지번만으로 건물을 식별할 수 없으며, 한 필지의 복수 건물·시점 차이도 확인해야 한다. 법정동 수준의 건물 연식 분포를 별도 참고지표로 만들 가능성은 있으나, 실거래 계약별 건축연도나 특정 건물의 연식으로 표시해서는 안 된다. 이 내용은 명세와 기존 원본을 바탕으로 한 연결 가능성 판단이며 실제 조인 검증 결과는 아니다.

Q-009는 API 응답 필드·호출 한도와 동별 분포의 활용 범위를 사람이 확인한 뒤 결정한다.
