# JU RENT · 전주시 대학가 월세 판단 서비스

전주대학교 리빙랩 프로젝트. 전주시 대학가에서 자취방을 구하는 대학생이
국토교통부 실거래 자료를 근거로 **동네를 고르고**, **제안받은 계약 조건이 적정한지 판단**하도록 돕는다.

## 핵심 기능
1. **동네·조건 추천** – 같은 예산에서 통학시간·면적·건축연도·버스 편의의 트레이드오프 비교
2. **계약 판단** – 사용자가 입력한 매물 조건을 비슷한 실거래 분포와 비교
3. **대학가 비교** – 전주 대학가별 월세 수준 비교

## 작업 규칙 (모든 도구 공통)
1. **코드는 이 저장소 하나에서만 관리한다.**
2. **결정 사항은 [`DECISIONS.md`](DECISIONS.md)에 기록한다.** 작업 전에 반드시 읽는다.
3. **숫자는 코드가 만든 것만 쓴다.** 기획서·발표에 쓰는 모든 수치는 [`NUMBERS.md`](NUMBERS.md)에 출처 파일과 함께 등록한다.

## 도구 역할
| 도구 | 역할 |
|---|---|
| Claude (claude.ai) | 기획·리서치·검토 총괄. Codex용 작업은 표·체크리스트 형태의 명세서(`specs/`)로 전달, 교수님용 기획서는 별도 작성 |
| Codex | 메인 개발 + 자체 테스트 (pytest, 고정값 회귀 테스트, ruff) |
| Claude Code | 고위험 로직만 교차 검증 (`[고위험]` PR의 변경분만) |
| ChatGPT | 선택: 2차 의견, 반론 검토, 발표 이미지 |

## 작업 흐름
```
Claude 명세서(specs/) → Codex 구현 + 자체 테스트 → [고위험]이면 Claude Code 교차 검증 → Claude 결과 해석·문서 반영
```

## 폴더 구조
```
jeonju-rent/
├─ README.md          프로젝트 개요 (이 파일)
├─ DECISIONS.md       결정 기록
├─ NUMBERS.md         수치 대장 (코드 산출 수치만)
├─ AGENTS.md          Codex 작업 지침
├─ CLAUDE.md          Claude Code 작업 지침
├─ .env.example       API 키 양식 (실제 키는 .env, 커밋 금지)
├─ data/
│  ├─ raw/            원본 CSV·API 응답 (커밋 제외, 용량·재배포 문제)
│  ├─ processed/      정제 데이터
│  └─ audit/          원본 파일 목록·해시(manifest.json), 집계(counts.json)
├─ specs/             작업 명세서 (Claude 작성 → Codex 입력)
├─ src/               수집·정제·분석 코드
├─ tests/             Codex 자체 테스트 (pytest)
├─ outputs/           코드가 만든 결과(표·그래프·json) → NUMBERS.md의 출처
├─ reviews/           Claude Code 고위험 검증 기록
└─ docs/              기획서, 발표 자료
```

## 시작하기
1. `.env.example`을 복사해 `.env`를 만들고 공공데이터포털 인증키를 넣는다.
2. `data/raw/`에 원본 데이터를 내려받는다 (방법은 `src/` 수집 스크립트 참고).
3. 분석 스크립트를 실행하면 `outputs/`에 결과가 생성된다.

## 데이터 출처
- 국토교통부 실거래가 공개시스템 / 공공데이터포털 전월세 실거래 API
- 부동산 플랫폼(네이버·직방·다방·당근) 데이터는 사용하지 않는다 (DECISIONS.md D-003).
